# Backend Error Internationalization Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use subagent-driven-development (recommended) or executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make every user-facing API error translatable by returning a stable machine code plus interpolation params, while the English text stays on the wire for logs, the CLI and webhook consumers.

**Architecture:** `packages/shared` gains a hand-written `MessageCode` const object (the wire contract). `AppError` carries `messageCode`/`params`; both transports (`tRPC errorFormatter` and `toErrorResponse`) serialize them, masked to `PUBLIC_CODES` exactly like `clientMessage()`. The web client maps code to a next-intl key through one hook in `shared/i18n`, with an exhaustiveness-checked key table so a code without a translation fails type-check.

**Tech Stack:** Bun, TypeScript strict, tRPC 11, next-intl 4.14.9, Zod 4.6.7, Vitest, Biome + Oxlint.

**Spec:** This plan is its own spec — scope decisions were agreed in conversation on 2026-11-04:
- In scope: error messages only, plus a verification pass over the already-localized auth email.
- Out of scope: audit log (`audit.mapper.ts` — being rewritten by the owner), notifications, `analysis/engine` rule titles, `apps/siem-server`, `packages/cli`, webhooks, Zod validation messages.
- Unknown-code fallback: generic message in production, raw English message in development.

## Global Constraints

- Bun only. Never `npm`/`yarn`/`pnpm`. Never introduce ESLint or Prettier.
- `bun run format` after edits — Biome rewrites imports and sorts object keys (`useSortedKeys`).
- Oxlint is type-aware: no `no-non-null-assertion`, no floating promises, kebab-case filenames, no `console.log`.
- Comments: none unless the code misreads without it; max two lines; no file headers.
- Branch: `feat/dxnx-<ticket>-backend-error-i18n` (`<ticket>` from the Linear issue). Lefthook rejects any branch without a `dxnx` segment.
- Commit scope must be one of `shared`, `web`, `tooling`. Never put the ticket in the subject; `prepare-commit-msg` appends `Closes DXNX-N` from the branch.
- Never `--no-verify`.
- `bun --filter @doxynix/web test <path>` goes through the Doppler wrapper — the Doppler CLI must be logged in locally; `CI=true` bypasses it.
- Locale file rules are enforced by `apps/web/scripts/check-locales.ts`: namespaces `PascalCase`, keys `lowercase_snake_case`, max nesting depth 3, identical placeholders across all 13 files.
- `messageCode` is emitted only when `isPublicCode(code)` is true. Non-public codes must serialize `messageCode: null` and `params: null`.
- English `message` is never removed from the wire.

```ts
export class AppError extends Error {
  public readonly code: ErrorCode;
  public readonly isUnexpected: boolean;
  public readonly kind: ErrorKind;
  public readonly messageCode: MessageCode | undefined;
  public readonly params: MessageParams | undefined;
  public readonly publicMessage: string;
  public readonly source: number | string | undefined;
  public readonly zodIssues: unknown;

  constructor(options: AppErrorOptions) {
    super(options.publicMessage ?? GENERIC_MESSAGE, { cause: options.cause });
    this.name = "AppError";
    this.code = options.code;
    this.isUnexpected = options.unexpected ?? false;
    this.kind = options.kind ?? "app";
    this.messageCode = options.messageCode;
    this.params = options.params;
    this.publicMessage = options.publicMessage ?? GENERIC_MESSAGE;
    this.source = options.source;
    this.zodIssues = options.zodIssues;
  }
```

export function messageKeyFor(code: MessageCode): ErrorMessageKey {
  return ERROR_MESSAGE_KEYS[code];
}

type ErrorPayload = {
  message?: string;
  messageCode?: MessageCode;
  params?: MessageParams;
};

function isRecord(value: unknown): value is Record<string, unknown> {
  return typeof value === "object" && value !== null;
}

export function readErrorPayload(error: unknown): ErrorPayload {
  if (!isRecord(error)) {
    return {};
  }

  const payload: ErrorPayload = {};

  if (typeof error.message === "string" && error.message.length > 0) {
    payload.message = error.message;
  }

  if (isRecord(error.data)) {
    if (typeof error.data.messageCode === "string" && KNOWN_CODES.has(error.data.messageCode)) {
      payload.messageCode = error.data.messageCode as MessageCode;
    }

    if (isRecord(error.data.params)) {
      const params: MessageParams = {};

      for (const [key, value] of Object.entries(error.data.params)) {
        if (typeof value === "string") {
          params[key] = value;
        }
      }

      payload.params = params;
    }
  }

  return payload;
}

export function useErrorMessage() {
  const t = useTranslations("Errors");

  return (error: unknown): string => {
    const { message, messageCode, params } = readErrorPayload(error);

    if (messageCode != null) {
      return t(messageKeyFor(messageCode), params);
    }

    if (!IS_PROD && message != null) {
      return message;
    }

    return t("generic");
  };
}

`apps/web/scripts/check-message-codes.ts` — fails when a public error throw has no code, or a code has no translation key:

```ts
import { readFileSync } from "node:fs";

import fg from "fast-glob";
import { join } from "pathe";

const ROOT = join(import.meta.dirname, "..");
const PUBLIC_CODES = [
  "BAD_REQUEST",
  "CONFLICT",
  "FORBIDDEN",
  "NOT_FOUND",
  "PARSE_ERROR",
  "PAYMENT_REQUIRED",
  "PRECONDITION_FAILED",
  "TOO_MANY_REQUESTS",
  "UNAUTHORIZED",
  "UNPROCESSABLE_CONTENT",
];

const files = await fg(["src/server/**/*.ts", "src/app/api/**/*.ts"], {
  absolute: true,
  cwd: ROOT,
  ignore: ["**/*.test.ts", "src/app/api/webhooks/**"],
});

const errors: string[] = [];
const throwRe = /new (?:TRPCError|AppError)\(\{([\s\S]*?)\n\s*\}\)/g;

for (const file of files) {
  const source = readFileSync(file, "utf8");
  let match = throwRe.exec(source);

  while (match != null) {
    const block = match[1] ?? "";
    const code = /code:\s*"([A-Z_]+)"/.exec(block)?.[1];

    if (code != null && PUBLIC_CODES.includes(code) && !block.includes("messageCode:")) {
      const line = source.slice(0, match.index).split("\n").length;
      errors.push(`${file}:${line} — public ${code} without messageCode`);
    }

    match = throwRe.exec(source);
  }
}

const en = JSON.parse(readFileSync(join(ROOT, "messages", "en.json"), "utf8")) as {
  Errors: Record<string, string>;
};
const keySource = readFileSync(join(ROOT, "src/shared/i18n/use-error-message.ts"), "utf8");
const codeRe = /^\s+([A-Z][A-Z0-9_]*): "([a-z0-9_]+)",$/gm;
let entry = codeRe.exec(keySource);

while (entry != null) {
  const [, , key] = entry;
  if (key != null && !(key in en.Errors)) {
    errors.push(`use-error-message.ts — code ${entry[1]} maps to missing key Errors.${key}`);
  }
  entry = codeRe.exec(keySource);
}

if (errors.length > 0) {
  console.error(errors.join("\n"));
  process.exit(1);
}

console.info(`check-message-codes: ${files.length} files OK`);
```

---
title: CLI reference
description: Every dxnx command, its arguments and its most useful options.
---

Most commands follow `dxnx <domain> <command>`; `status` is top-level. A command marked *default*
runs when you omit the subcommand. `--json` is listed only on commands that support it.

Domain aliases: `stats` (`analytics`), `activity` (`audit`), `doc` (`docs`), `pull-request` (`pr`),
`stage` (`staging`), `notif` (`notifications`), `gh` (`github`), `chat` (`agent`).

## Auth

| Command | Description | Key options |
| --- | --- | --- |
| `login` | Prompt for an API key, verify it and save it locally. | `-t, --token <token>` |
| `logout` | Remove the stored token from this machine. | — |
| `me` | Print the authenticated user. Alias: `whoami`. | `--json` |

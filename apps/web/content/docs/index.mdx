## What Doxynix does

Doxynix turns a Git repository into up-to-date documentation. It parses the code with
Tree-sitter to extract the real structure — files, top-level symbols, imports and file-level
dependency edges — and then uses LLMs to explain what that structure does. Because the model writes
on top of parsed facts instead of a raw file dump, the output stays anchored to the parsed structure
that actually exists.
